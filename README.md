## ✨ Fitur
- ✅ Responsive (mobile, tablet, desktop)
- ✅ Navbar sticky + scroll spy (menu otomatis menyala sesuai section)
- ✅ Hamburger menu untuk mobile
- ✅ Hero section dengan kode dekoratif
- ✅ Kartu hobi di-render via JavaScript (DOM), bisa dibuka dan ditutup saat diklik
- ✅ Efek emoji melayang saat kartu hobi dibuka
- ✅ Timeline education journey di-render via JavaScript
- ✅ Section kontak dengan tautan sosial media dan form bervalidasi (DOM)

## 🛠️ Teknologi
- HTML5 semantic
- CSS3 (Grid, Flexbox, CSS Variables, Media Queries), tanpa Tailwind/Bootstrap
- JavaScript ES6 (DOM, Event, IntersectionObserver)

## 🚀 Cara Jalankan
1. Clone repo
2. Buka `index.html` di browser
3. Atau deploy ke GitHub Pages / Netlify / Vercel
